# AI Usage Declaration

**Project:** ThreeOhNine — AI Algorithm Visualizer
**Authors:** Krasnobrizh Artyom, Orazgali Daulet

## AI tools used
- **Claude (Anthropic) — Claude Code and Claude Cowork** — project planning, the initial code of the algorithms and the automated tests, interface design (including the emerald glass theme and the “309” logo), documentation, the presentation, the English translation, and publishing the work to GitHub and Vercel.
- **UI/UX Pro Max** (a Claude Code design guide) — help with choosing design directions.

## No AI APIs inside the application
All AI algorithms in the application (BFS, DFS, UCS, A*, Hill Climbing, Minimax, Alpha-Beta) are written by hand in JavaScript. No ready-made AI API, pre-trained model or secret key is used.
