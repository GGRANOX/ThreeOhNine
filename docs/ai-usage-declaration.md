# AI Usage Declaration

**Жоба:** ThreeOhNine — AI Algorithm Visualizer
**Авторлар:** Krasnobrizh Artyom, Orazgali Daulet

## Қолданылған AI құралдары
- **Claude Code (Anthropic, Claude Sonnet 5.5)** — жобаны жоспарлау, алгоритмдердің бастапқы коды мен автотесттерді жазу, интерфейс дизайны, құжаттама мен презентация жобасын дайындау, жұмысты GitHub-қа және Vercel-ге жариялау.
- **UI/UX Pro Max** (Claude Code дизайн нұсқаулығы) — дизайн бағыттарын таңдауға көмек.

## Қосымшада AI API қолданылмайды
Қосымшаның ішіндегі барлық AI алгоритмдері (BFS, DFS, UCS, A*, Hill Climbing, Minimax, Alpha-Beta) JavaScript тілінде қолмен жазылған. Дайын AI API, дайын модель немесе құпия кілт қолданылмайды.

## Авторлардың жауапкершілігі
Авторлар кодты оқып, іске қосып, тестіледі (`npm test`, 11 тест) және әр алгоритмнің жұмысын түсіндіре алады. AI көмегімен жасалған материалдарды авторлар тексеріп, өз жауапкершілігіне алады.

| Автор | Растау |
|---|---|
| Krasnobrizh Artyom | Жоғарыдағы мәліметтермен келісемін |
| Orazgali Daulet | Жоғарыдағы мәліметтермен келісемін |
